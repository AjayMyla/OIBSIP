# AVORA — Landing Page

> **A Vision. One Direction.**

AVORA is a modern, responsive landing page created as part of my Web Development internship.

The project focuses on building a polished user interface using only **HTML5 and CSS3**, with emphasis on responsive layouts, visual hierarchy, clean typography, and modern UI design.

## ✨ Features

* Sticky navigation bar
* Hero section with call-to-action
* Modern product dashboard visual
* Features section
* About section
* Customer testimonials
* Final call-to-action section
* Responsive layout
* Mobile-friendly design
* CSS hover effects and animations
* Consistent color system
* Semantic HTML structure
* No JavaScript required

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* CSS Variables
* Responsive Media Queries
* Google Fonts

## 🎨 Design

AVORA uses a dark navy interface with an emerald/mint accent color to create a modern SaaS-style visual identity.

## 🚀 How to Run

No installation or dependencies are required.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, open the project in VS Code and use a local development server such as Live Server.

## 📱 Responsive Design

The landing page is designed to adapt to:

* Desktop
* Laptop
* Tablet
* Mobile
* Small mobile screens

Responsive behavior is implemented using CSS media queries, Flexbox, and Grid.
